## ポモドーロ×フロー状態測定タイマー

標準25分作業+5分休憩のポモドーロタイマーに「フロー状態スコア（集中度1-5）」の自己申告を組み合わせ、どの時間帯・タスク種別で最も集中できるかをヒートマップで可視化する生産性分析ツール。

### 機能
- ポモドーロタイマー: 25分/5分/15分（作業/短休憩/長休憩）切り替え・SVG リング進捗表示
- タイマー終了時にフロー状態スコア（1〜5★）とタスク種別（コーディング/ライティング/会議/その他）を入力するモーダル
- 1週間のヒートマップ（時間帯 × 曜日）: 平均集中度を赤グラデーションで表示
- タスク種別ごとの平均集中度バーグラフ
- 累計ポモドーロ数・累計集中時間・平均集中度スコアの表示
- Notification API 対応（タイマー終了時のブラウザ通知）
- localStorage による全セッション記録の永続保存（最大500件）

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- SVG（リング形タイマー進捗）
- Notification API（ブラウザ通知）
- localStorage（セッション記録保存）
